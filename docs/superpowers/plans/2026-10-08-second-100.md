## Ownership and integration

Agents own new feature directories, their focused tests and the named evidence files. Root owns App.tsx, app route boundary, Vite chunking, shared contracts, navigation, full browser verification, release docs and deployment. Feature components export named Journey, Explorer, Reports, Maintenance with `{repository,snapshot}`. QuestionWorkpad receives `{repository,session,question}` and optional `answered`; no shared session mutation. All personal state uses bounded workspace entries and normalises untrusted restored values. Evidence agent owns its new EvidenceHealth component and source baseline/audit data, coordinates any source changes.
